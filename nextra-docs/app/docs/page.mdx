# Privacy Protocol Documentation

Privacy Protocol is a relayer-first privacy middleware for EVM dApps.

## Install

<Tabs items={["npm", "yarn", "pnpm"]}>
  <Tabs.Tab>```bash npm install privacy-protocol ethers ```</Tabs.Tab>
  <Tabs.Tab>```bash yarn add privacy-protocol ethers ```</Tabs.Tab>
  <Tabs.Tab>```bash pnpm add privacy-protocol ethers ```</Tabs.Tab>
</Tabs>

<Callout type="info" emoji="⚡">
  Circuit artifacts are bundled in the SDK. No manual circuit import is
  required.
</Callout>

## Integration Paths

- `privacy-protocol/core`
- `privacy-protocol/hooks`

## Relay Lifecycle

Private actions move through:

1. `queued` (`relay:<request_id>`)
2. `submitted` (on-chain tx hash available)
3. `confirmed` (receipt success or revert)

## Developer Flow

<Steps>
### Configure SDK
Set pool + relayer values in app environment and instantiate the SDK.

### Execute Private Actions

Use core methods or hooks for deposit, executeAction, and withdraw.

### Render Lifecycle

Show queued/submitted/confirmed states in transaction UI.

</Steps>
